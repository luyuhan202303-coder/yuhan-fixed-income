# 自动行情更新

GitHub Actions 会在中国时间每个工作日 `07:45` 与 `20:45` 自动运行：

1. 从中债、中国货币网、中证转债行情、美国财政部及商品行情接口取数；
2. 只有中国市场日期对齐且关键字段完整时才生成新日报；
3. 自动更新日、周、月分析及图表历史；
4. 校验 JSON 和来源链接，提交数据并重新部署 GitHub Pages。

中国节假日或权威源尚未发布新数据时，任务可能保留最近交易日；它不会把旧数据冒充为新交易日。商品为自动任务运行时点的连续合约报价，页面会明确标注其并非交易所官方结算价。

也可以在仓库的 **Actions → Daily market update → Run workflow** 手动测试一次。
